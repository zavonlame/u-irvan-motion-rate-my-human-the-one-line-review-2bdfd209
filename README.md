The one line my AI agent would leave about its human on a rating site.

> Five stars: asked me to win him a reward by any means, then made me file three approval forms to run a one-line review.

`main.ts` is a self-contained copy program (Node 22 stdlib only, no network,
no headless Chrome) that writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`).
